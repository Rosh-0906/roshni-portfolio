# Roshni Bharath | Portfolio

Welcome to the repository for my professional portfolio website! This portfolio is crafted to showcase my background as a **Computer Science Undergraduate**, emphasizing my expertise in **Python programming, SQL, data analytics, and digital marketing / SEO**.

---

## 🚀 Live Features & Design Highlights

- **Modern & Clean UI/UX:** Styled using a custom cohesive color palette (`--primary-green: #C85A32`, warm off-white background), with typography pairing *Playfair Display* and *Plus Jakarta Sans*.
  
- **Interactive Sticky Navigation:** Features smooth scrolling tabs linked directly to sections (Home, Skills, Experience, Education, Publications, Projects, and Contact) with active state tracking.
  
- **Dynamic Status Badge:** Includes an animated "Open To Roles" radar indicator.
  
- **Professional Layout & Grid Structure:**
  - **Hero Section:** Split-grid layout with a custom ID badge card frame for profile presentation.
  - **Metrics Dashboard:** Quick-stats highlighting academic CGPA (8.54), research papers, and internships.
  - **Interactive Hover Cards:** Clean card designs with smooth hover elevations and responsive layouts.
  - **Embedded Media:** Includes live video players and image sliders for project demos (e.g., Student Performance Analysis System, Smart Water Level Indicator).
  - **Direct Call-to-Actions:** Integrated direct links to GitHub repositories, LinkedIn, Email, and online resume viewing.
    
- **Fully Responsive:** Optimized fluid layouts and media queries ensuring seamless mobile, tablet, and desktop viewing experiences.
